## Voice integration (PR #73)

Roy delivered recordings for the 5 newer scenes (source folder was
`~/Documents/דיבוב 2`). Locked decisions:

- **Male Hebrew narrator** for the 5 new scenes: `train`, `bus`, `quiet-bar`,
  `house-party`, `supermarket` (intro/mid/end each).
- **English falls back to the Hebrew audio** for these 5 — the `en` entries in
  `VOICE_TRACKS` point at the same files so English sessions aren't silent until
  English narration is recorded.
- **The 4 original scenes were left untouched.** Their committed audio was
  already byte-identical to Roy's source folder, so "replacing" them was a
  genuine no-op (`beach`/`park`/`cafe`/`road` unchanged; `beach` still has
  genuinely separate en/he recordings).

Result: every `SCENE_ORDER` scene now resolves to real bundled clips in both
languages — `getVoiceClips` no longer returns placeholders for any shipping
scene. Test coverage was broadened to assert this across all scenes; the old
placeholder test now exercises the defensive no-tracks branch via a cast key.
`content.ts` full suite: 442 tests / 43 suites green, `content.ts` at 100%.

`VOICED_SCENES` in `content.ts` now means **scenes with written on-screen
caption scripts** (still the original four) — distinct from "scenes with
recorded audio" (now all nine).
